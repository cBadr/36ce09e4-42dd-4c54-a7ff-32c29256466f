
# مشروع واصل - منصة الحملات الإعلانية الصوتية

## ملخص المشروع

منصة "واصل" هي نظام SaaS متكامل لإدارة الحملات الإعلانية الصوتية، تتيح للمستخدمين إنشاء وإدارة حملات اتصال آلية، وتشغيل رسائل صوتية مخصصة، ثم تحويل المكالمات إلى مديري الحملات.

## الميزات المطلوبة

- [ ] نظام تسجيل الدخول والمصادقة
- [ ] لوحة تحكم المستخدم مع مؤشرات الأداء الرئيسية
- [ ] إدارة الحملات الإعلانية
- [ ] تتبع نتائج الحملات وتحليلها
- [ ] نظام دفع متكامل مع Stripe وPayPal
- [ ] لوحة تحكم الأدمن مع إدارة المستخدمين والصلاحيات
- [ ] إدارة السجلات والجلسات

## التقنيات المستخدمة

- React مع TypeScript
- نظام واجهات shadcn/ui
- Tailwind CSS للتصميم
- Recharts لعرض الرسوم البيانية
- React Router للتنقل
- Stripe و PayPal لأنظمة الدفع (قيد التنفيذ)
- خط Cairo للدعم العربي
